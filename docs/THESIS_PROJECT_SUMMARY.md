# 论文项目说明：基于移动协作机器人的大型工件视觉检测系统

> 本文档按当前巡检/视觉检测方向撰写，可作为毕业论文中“课题内容、系统设计、算法设计与创新点”部分的材料草稿。  
> 当前论文与演示默认不依赖网页前端和 fake driver。

## 1. 课题背景与研究目标

大型工件在制造、装配和维护过程中通常需要进行表面质量检测。传统人工检测方式依赖经验，存在检测效率低、重复性差、危险区域作业风险高、检测结果难以结构化追溯等问题。对于尺寸较大、检测点分布分散、表面姿态变化明显的工件，固定相机或固定机械臂难以覆盖全部检测区域，因此需要一种能够在较大空间内移动、并在局部区域进行精细观测的机器人检测系统。

本课题设计并实现了一套基于移动协作机器人的大型工件视觉检测系统。系统由 AGV 移动底盘、六自由度协作机械臂、末端深度相机、工业相机和 ROS2 控制软件组成。系统能够按照预先配置的检测站位自动导航，到达站位后驱动机械臂运动到预设观测姿态，通过深度相机进行局部工作距微调，再触发工业相机采集图像并完成缺陷检测与结果记录。

本课题的总体目标包括：

1. 构建移动底盘、机械臂、深度相机、工业相机之间的 ROS2 分布式系统。
2. 实现面向大型工件的多站位自动巡检流程。
3. 设计一种适用于非平面工件表面的视觉工作距自适应微调方法。
4. 实现图像缺陷检测、检测结果结构化输出和实验数据记录。
5. 建立可真机联调、可回放验证、可扩展的工程化软件架构。

## 2. 系统组成与实现内容

本项目的硬件系统主要包括：

- 仙宫智能 AGV：负责大范围移动和站位导航。
- 大族 E05 / Elfin5 协作机械臂：负责末端相机的局部姿态调整。
- Intel RealSense 深度相机：安装在机械臂末端，用于获取局部深度信息并辅助工作距微调。
- 海康工业相机：安装在机械臂末端，用于采集高质量缺陷检测图像。
- Jetson Orin AGX：作为机器人端计算平台，运行 ROS2、驱动节点、任务编排节点和算法节点。
软件系统采用 ROS2 Humble 架构，按功能划分为驱动层、控制层、算法层、协调层和基础设施层。当前论文与系统演示默认通过 ROS2 launch、RViz、ros2 CLI 和实验脚本完成，不依赖网页前端。

## 3. 已完成的主要工作

### 3.1 AGV 底盘驱动与导航接口封装

项目实现了 `agv_driver` 包，用于封装 AGV 厂商 TCP API。该模块对上层屏蔽底盘通信细节，提供统一 ROS2 接口：

- 接收 `goal_pose` 或站点名称，下发导航任务。
- 发布 AGV 连接状态、导航状态、当前位姿、速度和错误码。
- 为任务协调节点提供到位判断依据。
- 为导航地图和站位可视化预留 `get_nav_map` 服务接口。

通过该模块，系统可以将大型工件周围的检测点组织成多个 AGV 站位，并按任务顺序逐站执行。

### 3.2 机械臂驱动与运动控制

项目集成了 Elfin 机械臂底层驱动，并构建了 `arm_driver` 和 `arm_controller` 两层结构：

- `arm_driver` 负责机械臂底层 EtherCAT 通信、关节状态发布、使能、停止、清错等基础能力。
- `arm_controller` 负责上层运动控制，提供关节空间运动和末端位姿运动接口。

在巡检任务中，机械臂主要执行两类动作：

1. 运动到 YAML 配置中的预设关节角，使相机到达大致观测位姿。
2. 根据深度微调算法输出的位姿偏移，进行小范围末端位姿修正。

### 3.3 多站位巡检任务状态机

项目实现了 `task_coordinator` 任务编排节点。该节点以状态机方式统一调度 AGV、机械臂、深度相机和缺陷检测模块，完成自动巡检流程。

巡检状态机如下：

```text
IDLE
  -> MOVING_TO_STATION
  -> ARM_PRESET
  -> DEPTH_ADJUST
  -> CAPTURING
  -> 下一站位 / COMPLETED
```

各阶段含义如下：

- `MOVING_TO_STATION`：向 AGV 下发导航目标，等待底盘到位并停止。
- `ARM_PRESET`：调用机械臂控制服务，使机械臂到达预设观测姿态。
- `DEPTH_ADJUST`：读取 RealSense 深度图，计算当前工作距离，并执行微调。
- `CAPTURING`：触发工业相机拍照，调用缺陷检测算法，发布结果。
- `COMPLETED`：所有站位检测完成。

巡检点位由 YAML 文件配置，包含站位名称、AGV 位姿、机械臂预设关节角、目标工作距离、距离容差和微调方向等参数。这种配置驱动方式降低了系统复杂度，也便于现场标定和调试。

### 3.4 深度相机工作距自适应微调

大型工件表面可能存在曲面、倾斜面、局部凹凸和装配误差。如果机械臂只按照固定关节角拍照，相机与工件表面之间的距离可能偏离最佳成像工作距，导致图像模糊、尺度变化或局部区域失焦。

为解决这一问题，项目设计了基于 RGB-D 的末端工作距微调算法。算法在机械臂到达预设观测姿态后，利用 RealSense 对目标区域进行深度测量，根据测得距离与目标距离之间的误差，驱动机械臂末端沿观测方向进行小范围闭环调整。

基础版本采用中心 ROI 深度中值作为距离估计：

```text
d_current = median(depth[u, v]), (u, v) in ROI
e = d_current - d_target
```

当误差满足：

```text
|e| <= tolerance
```

时认为工作距满足拍照要求；否则执行限幅比例控制：

```text
step = clamp(kp * e, -max_step, max_step)
```

并将该偏移转换为机械臂规划坐标系下的末端目标位姿。

针对目标表面不是理想平面的情况，论文中进一步提出局部点云表面估计方法：在目标 ROI 内将深度像素反投影为三维点云，对局部点云进行滤波，然后通过 PCA 或 RANSAC 拟合局部切平面，得到局部表面中心和法向量。系统不假设整个工件为平面，而只在局部区域近似为切平面，从而适应大型工件表面的局部曲率变化。

局部点云反投影公式为：

```text
X = (u - cx) * Z / fx
Y = (v - cy) * Z / fy
Z = depth(u, v)
```

局部表面可表示为：

```text
P = {p_i | i = 1, 2, ..., N}
c = mean(P)
n = PCA(P) 中最小特征值对应的特征向量
```

相机到局部表面的距离可计算为：

```text
d = |(o - c) · n|
```

其中 `o` 为相机坐标系原点，`c` 为局部表面中心，`n` 为局部法向量。该方法能够在非平面工件表面上估计局部工作距，并为后续位姿微调提供依据。

### 3.5 缺陷检测与结构化结果输出

系统设计了 `defect_detector` 算法模块，用于对工业相机采集的图像进行缺陷检测。该模块采用“ROS IO 与算法核心解耦”的设计方式，内部可替换为传统图像处理、深度学习目标检测、语义分割或异常检测模型。

论文实现可采用两条技术路线：

1. 基于 YOLOv8-seg 的缺陷实例分割  
   适用于存在一定数量缺陷标注数据的场景。模型输出缺陷类别、边界框、mask 和置信度。

2. 基于 PatchCore / PaDiM 的少样本异常检测  
   适用于缺陷样本少、正常样本较容易采集的工业场景。模型输出异常热力图，再经阈值分割得到缺陷区域。

检测结果经过后处理后，形成结构化数据：

- 缺陷类别
- 置信度
- 缺陷区域 bbox / mask
- 缺陷面积
- 缺陷中心位置
- 严重等级
- 原图和标注图媒体 ID

这些结果可发布为 ROS2 消息，并保存为图像文件和 CSV 实验记录，支持任务结果回看和后续质量追溯。

### 3.6 ROS2 状态输出与实验记录

当前论文主线不依赖网页前端。系统通过 ROS2 topic、service、RViz 和实验脚本完成状态观察、任务控制和数据记录。

该部分应完成以下功能：

- 通过 ROS2 service 启动、暂停、恢复、停止任务。
- 通过 `/inspection/state` 输出系统状态。
- 保存每站位原图、标注图、深度微调数据和耗时数据。
- 输出可用于论文统计的 CSV 文件。

`inspection_gateway` 和 `inspection_sim` 在仓库中作为历史/可选模块保留，但不作为当前论文系统的必要组成。

## 4. 系统总体工作流程

系统执行一次巡检任务的流程如下：

```text
1. 通过 ROS2 launch 启动巡检系统
2. 通过 ROS2 service 启动巡检任务
3. task_coordinator 加载 YAML 站位序列
4. AGV 导航到第一个检测站位
5. 机械臂运动到该站位对应的预设观测姿态
6. RealSense 获取目标区域深度图
7. 深度微调算法估计当前工作距并修正末端位姿
8. 工业相机触发拍照
9. defect_detector 完成缺陷检测并发布结构化结果
10. 系统保存原图、标注图和实验记录
11. 系统进入下一站位，直到所有检测点完成
```

## 5. 关键算法设计

### 5.1 工作距微调算法

工作距微调算法的输入为：

- 对齐到彩色图的深度图 `D`
- 相机内参 `fx, fy, cx, cy`
- 目标 ROI
- 目标工作距离 `d_target`
- 距离容差 `epsilon`
- 最大调整步长 `s_max`

输出为：

- 是否满足工作距要求
- 若不满足，输出机械臂末端目标位姿

算法步骤如下：

```text
Input: depth image D, camera intrinsics K, target ROI, d_target
Output: adjusted TCP pose or success flag

1. Extract valid depth points from ROI.
2. Remove invalid depth values and outliers.
3. Estimate local depth:
   - simple mode: median depth
   - enhanced mode: local point cloud plane fitting
4. Compute distance error:
   e = d_current - d_target
5. If |e| <= epsilon:
   return success
6. Compute bounded control step:
   s = clamp(kp * e, -s_max, s_max)
7. Transform adjustment vector from camera frame to arm planning frame.
8. Generate target TCP pose while keeping orientation unchanged.
9. Call MoveToPose service.
10. Repeat until convergence or retry limit is reached.
```

### 5.2 非平面表面的局部点云估计

对于曲面或局部不规则工件，单点深度或中心 ROI 平均值容易受到边缘、孔洞和反光区域影响。为提高鲁棒性，增强版本算法使用局部点云估计目标区域的局部表面。

主要步骤包括：

1. ROI 深度反投影为点云。
2. 使用深度范围约束去除无效点。
3. 使用统计滤波或中值滤波去除离群点。
4. 使用 PCA 估计局部法向量。
5. 根据局部曲率判断该区域是否适合进行微调。
6. 以局部切平面距离作为工作距反馈量。

局部曲率可表示为：

```text
curvature = lambda_min / (lambda_1 + lambda_2 + lambda_3)
```

当曲率过大或有效点数量不足时，说明 ROI 内表面不稳定，系统可以选择重新采样、扩大 ROI、切换观测姿态或报告该检测点微调失败。

## 6. 创新点

### 创新点 1：面向大型工件的移动机械臂多站位视觉检测架构

传统固定工位视觉检测系统难以覆盖大型工件的全部检测区域。本课题将 AGV 的大范围移动能力与协作机械臂的局部灵活调整能力结合，构建了“移动站位 + 末端精调 + 局部视觉检测”的系统架构。该架构能够在大型工件周围按站位自动移动，并在每个站位完成局部高精度观测。

### 创新点 2：配置驱动的巡检任务编排方法

系统没有采用复杂的全局路径和姿态实时规划，而是将站位、机械臂姿态、目标工作距和微调参数统一写入 YAML 配置文件，由任务状态机按配置顺序执行。该方法降低了现场部署难度，便于工程调试和任务复现，适合毕业设计和工业原型系统落地。

### 创新点 3：基于 RGB-D 局部点云的非平面工件工作距自适应微调

针对大型工件表面不一定为平面的实际情况，本文提出局部点云工作距估计方法。算法不假设整个工件表面为平面，而是在目标 ROI 内建立局部表面模型，通过深度中值、PCA 法向估计和局部切平面距离计算当前工作距。该方法能够提高相机成像距离的一致性，减少固定预设位姿带来的拍照误差。

### 创新点 4：深度反馈与机械臂位姿控制结合的闭环观测方法

系统将 RealSense 深度测量结果作为反馈量，引入比例限幅控制，将深度误差转换为机械臂末端位姿修正量。相比单纯依赖标定点位和机械臂重复定位精度，该方法具有一定自适应能力，可以补偿 AGV 停靠误差、机械臂安装误差、工件摆放误差和表面高度变化。

### 创新点 5：视觉检测结果的结构化表达与实验数据闭环

系统不仅完成图像采集和缺陷检测，还将缺陷类别、位置、置信度、面积、标注图和任务状态统一封装，并保存为 ROS2 消息、图像文件和 CSV 记录。这使检测结果具备可追溯性，满足论文实验统计、异常定位和结果回看的需求。

### 创新点 6：面向真实硬件联调的 ROS2 分层工程架构

项目采用驱动层、控制层、算法层、协调层和基础设施层的分层设计，避免将设备协议、控制逻辑和算法代码混杂在同一节点中。算法模块支持使用真机数据或离线回放数据验证，该设计提高了系统的可维护性、可测试性和扩展性。

## 9. 论文中的项目总结表述

本文围绕大型工件表面自动化检测需求，设计并实现了一套基于移动协作机器人的视觉检测系统。系统以 ROS2 为核心通信框架，集成 AGV 移动底盘、协作机械臂、深度相机和工业相机，实现了多站位自动导航、机械臂预设观测、深度工作距微调、工业图像采集、缺陷检测和实验结果记录等功能。

针对大型工件表面形态复杂、固定拍照位姿难以保证成像距离一致的问题，本文设计了基于 RGB-D 局部点云的工作距自适应微调算法。该算法在目标检测区域内提取深度信息，估计局部表面距离和法向，并通过机械臂末端位姿修正实现观测距离闭环控制，从而提高图像采集质量和检测稳定性。

通过系统实验验证，本文所设计的移动机械臂视觉检测系统能够完成大型工件多站位巡检任务，并具备较好的工程可扩展性和实际应用价值。
